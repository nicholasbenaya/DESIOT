Mata Kuliah: DESIOT (ITS)
Target Board: ESP32-S3 DevKit
Kelompok 4 Orang (Max 5 Menit)
PRINSIP KELISTRIKAN KRUSIAL (PENTING DIBACA SEBELUM MERANGKAI):
Pin VIN adalah Jalur Input Daya Regulator LDO Internal, BUKAN Output Catu Daya Beban! Jangan mengambil daya motor pompa air DC 5V atau coil relay langsung dari pin VIN ESP32-S3. Motor pompa adalah beban induktif yang menyedot arus lonjakan (inrush current) 500mA–1A. Menarik arus beban motor melalui jalur PCB ESP32-S3 akan memicu voltage sag yang menyebabkan ESP32-S3 Brownout Reset (restart berulang kali) atau terbakar bila ditenagai baterai 9V. Solusi Wajib: Gunakan adaptor 5V eksternal mandiri untuk relay & pompa dengan skema Common Ground.

2. Identifikasi Terminal Modul Relay Berbahasa Mandarin (Hanzi)

Pada modul relay biru (Songle / generic), silkscreen PCB terminal 3 sekrup output umumnya bertuliskan karakter Mandarin. Berikut panduan pencocokannya:

常开 / 开
NO (Normally Open)
HUBUNGKAN KE POMPA (+)
Arus baru mengalir saat relay ON (bunyi klik).
公 / 公共端
COM (Common)
HUBUNGKAN KE +5V ADAPTOR
Terminal bersama sumber daya arus listrik.
常闭 / 闭
NC (Normally Closed)
KOSONGKAN / JANGAN DIPAKAI
Terhubung saat relay OFF, terputus saat ON.
Trik Multimeter (Buzzer Mode): Saat relay mati tanpa listrik, tempelkan probe di terminal tengah (COM) dan salah satu terminal samping. Terminal yang berbunyi "BEEP" adalah NC (常闭), sedangkan terminal yang diam (tidak bunyi) pasti adalah NO (常开).

3. Tabel Pengkabelan Fisik Lengkap (ESP32-S3 DevKit)
A. Node 1: Aktuator Pompa Air DC (Generic OnOff Server)
Dari Komponen / Pin Terhubung Ke Fungsi & Catatan Teknis
Relay: Pin IN GPIO 10 ESP32-S3 Sinyal kontrol digital aktuasi pompa
Relay: Pin VCC +5V Adaptor Eksternal Daya coil relay elektromagnetik (terpisah dari ESP32)
Relay: Terminal COM (公) +5V Adaptor Eksternal Sumber tegangan penggerak motor pompa
Relay: Terminal NO (常开) Kabel Positif (+) Pompa DC Menghubungkan arus ke motor saat relay dipicu ON
Relay: Pin GND GND Common Ground Ground referensi modul relay
Pompa DC: Kabel Negatif (-) GND Common Ground Menutup sirkuit daya motor pompa
ESP32-S3: Pin GND GND Common Ground Wajib Common Ground menyamakan level logika sinyal IN
ESP32-S3: Port USB Charger USB 5V Mandiri Daya mikrokontroler bebas noise motor
B. Node 2: Sensor Kelembapan Tanah (Low Power Node - Baterai Mandiri)
Dari Komponen / Pin Terhubung Ke Fungsi & Catatan Teknis
Sensor: Pin AOUT GPIO 4 ESP32-S3 Output analog kadar air (ADC1_CH3 pada ESP32-S3)
Sensor: Pin VCC 3V3 ESP32-S3 Wajib 3.3V agar output ADC aman (0–3.0V). Jangan ke VIN!
Sensor: Pin GND GND ESP32-S3 Ground sensor kapasitif
Baterai: Kutub Positif (+) VIN ESP32-S3 Input ke regulator internal LDO (Baterai 18650 x 2 / 7.4V / 9V)
Baterai: Kutub Negatif (-) GND ESP32-S3 Ground baterai mandiri
C. Node 3 & Node 4: Jaringan Mesh & Gateway MQTT
Simpul Koneksi Daya & Data Peran dalam Jaringan
Node 3 (Relay/Friend) Port USB ke Charger HP 5V (Tanpa sensor luar) Radio RX siaga 100% menyimpan antrean pesan LPN & merelai paket
Node 4 (Gateway Wi-Fi) Port USB ke Laptop Host (CH343 / COM6) Menangkap paket mesh & mem-publish data JSON ke Mosquitto (1883)
